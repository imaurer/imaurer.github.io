# PangoPup

2026-08-01 · https://www.imaurer.com/projects/pangopup/

PangoPup is an open-source, GPL-licensed Rust service built on the Pangolin model. It provides fast, local splice predictions for GRCh38 variants. Bioinformatics and clinical genomics teams can run it on their own hardware and keep variant data inside their walls. The project is active.
